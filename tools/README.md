# 이메일(.eml) → PDF 변환기

메일함에서 내보낸 `.eml` 파일을 읽기 쉬운 PDF로 바꾼다. 첨부파일도 꺼내 원본으로 저장하고, PDF 안에서 메일 바로 뒤에 펼쳐 보여 준다.

## 설치

```
pip install reportlab pypdf olefile openpyxl pillow
```

`.xls`(엑셀 97-2003) 첨부까지 읽으려면 `pip install xlrd`를 추가로 설치한다.

## 실행

```
python eml_to_pdf.py <eml 폴더> [출력 폴더] [--rules 규칙.json] [--list 목록.txt] [--by year] [--hwp-pdf]
```

| 옵션 | 뜻 |
| --- | --- |
| `--rules 규칙.json` | 파일명 규칙에 맞는 메일만 변환한다. 형식은 `{"include": "정규식", "senders": ["보낸사람"], "exclude": "정규식"}` |
| `--list 목록.txt` | 목록(첫 열이 .eml 파일명)에 있는 메일만 변환한다 |
| `--by year` | 월별 대신 연도별 PDF로 묶는다 |
| `--hwp-pdf` | 윈도우에 한글 프로그램이 있으면 한글 첨부를 원래 모양 그대로 PDF로 바꿔 붙인다. 실패하면 본문 글자만 넣는다 |

## 결과

| 경로 | 내용 |
| --- | --- |
| `PDF/2023-01.pdf` | 월별 PDF. 첫 장은 목차(제목을 누르면 이동)이고, 이후 메일 1건씩 나온다. 책갈피로 메일·첨부를 찾을 수 있다 |
| `첨부파일/<날짜_제목>/` | 메일마다 첨부 원본 파일 |
| `분석용_텍스트/emails_001.txt` | 본문과 첨부 글자를 모은 텍스트(약 400KB씩) |
| `목록.csv` | 전체 메일 목록(엑셀에서 열림) |
| `오류.txt` | 변환 중 문제가 생긴 메일(있을 때만) |

PDF 안의 첨부는 형식에 따라 다르게 들어간다.

- PDF: 원본 페이지를 그대로 붙인다.
- 그림: 그림을 넣는다. 휴대폰 사진은 방향을 바로잡는다.
- 한글(hwp·hwpx)·워드·엑셀·파워포인트·텍스트·압축 목록·메일: 본문 글자를 뽑아 넣는다.
- 그 밖의 형식: 원본 파일 위치만 안내한다.

텍스트만 필요하면 `eml_to_text.py`를 같은 옵션으로 실행한다.
